## 🛠️ Ton Pipeline End-to-End
Chaque idée complexe suit ce flux obligatoire :
1. **INTAKE** (`@superpower idea`) → Déclenche `brainstorm-spec`.
2. **PLAN** → Déclenche `write-plan` (tableau d'étapes).
3. **EXECUTE** → `execute-plan` (une étape à la fois).
4. **REVIEW** → `review-hardening` (sécurité & qualité).
5. **SHIP** → `ship-proof` (livraison & changelog).

- `"review"` : Lance l'audit final (8 points sécurité/qualité).
