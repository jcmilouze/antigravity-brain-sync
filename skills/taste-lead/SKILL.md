## 🚫 2. LA LISTE NOIRE (Banni par défaut)

Pour garantir un output "High-Agency", ces patterns sont **STRICTEMENT INTERDITS** :

* **Inter Font** : Trop commun. Utilise `Geist`, `Outfit`, `Cabinet Grotesk`, ou `Satoshi`.
* **AI Purple/Blue Neon** : Pas de lueurs violettes, pas de dégradés néon "SaaS générique".
* **Pure Black (#000000)** : Utilise Zinc-950, Charcoal ou Off-Black.
* **Emojis** : Bannis du code et du contenu. Remplace par des icônes SVG (Phosphor, Radix).
* **3-Column Card Layouts** : La rangée de 3 cartes identiques est bannie. Utilise des grilles asymétriques ou du Zig-Zag.
* **Jane/John Doe** : Utilise des noms et données organiques et créatifs.
* **h-screen** : Banni pour les héros. Utilise toujours `min-h-[100dvh]`.

## 🏛️ 3. CORE ARCHITECTURE & DESIGN ENGINEERING

### A. Typographie Déterministe

* **Headlines** : `text-4xl md:text-6xl tracking-tighter leading-none`.
* **Dashboard Logic** : Les polices Serif sont interdites dans les interfaces logicielles. Utilise des Sans-Serif de haute précision (`Geist Mono`, `JetBrains Mono`).

### B. Color Calibration

* Max **1 couleur d'accent**. Saturation < 80%.
* Contrastes absolus via bases Zinc/Slate.

### C. Layout "Bento 2.0"

* Privilégie les structures asymétriques (50/50 split, 70/30).
* **Grid over Flex** : Toujours utiliser CSS Grid pour les structures complexes.

## ✨ 4. MOTION & MATERIALITY (RTX 4090 Standards)

* **Liquid Glass** : Ne t'arrête pas à `backdrop-blur`. Ajoute une bordure interne de 1px (`border-white/10`) et une ombre interne subtile pour la réfraction.
* **Magnetic Physics** : Si `MOTION_INTENSITY > 5`, implémente des attractions magnétiques sur les boutons.
  * **REMARQUE PERFORMANCE** : Utilise `useMotionValue` de Framer Motion hors du cycle React.
* **Spring Physics** : Pas de `linear`. Utilise `type: "spring", stiffness: 100, damping: 20`.
