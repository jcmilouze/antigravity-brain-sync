# Antigravity Brain Sync
Synchronisez votre mémoire agentique entre PC et Mac via Git.

## Fonctionnalités
- 📥 **Pull with Rebase** : Récupération propre de la conscience collective.
- 📤 **Push with History** : Archivage des compétences et souvenirs locaux.
- 🌀 **Pulsing Status Bar** : Indicateur en temps réel de dirty/behind.
- ⚙️ **Configurable** : Liaison facile à votre repo GitHub privé.

## Installation
Installez le fichier `.vsix` généré via le menu "Extensions" de VS Code.
