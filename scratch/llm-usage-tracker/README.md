# Antigravity LLM Tracker

**Extension VS Code**: Suivez l'utilisation des modèles locaux en temps réel.

## Caractéristiques
- **Polling API Ollama**: Vérifie `localhost:11434/api/ps` toutes les 10 secondes.
- **Chronométrage d'usage**: Enregistre le temps passé par chaque modèle local.
  
## Installation
1. Téléchargez l'extension depuis la Marketplace de VS Code.
2. Redémarrez VS Code pour activer l'extension.

## Utilisation
L'interface de l'extension affiche automatiquement les données d'utilisation des modèles locaux.
